# React Project

A modern React + Vite project built as a digital banking landing page focused on customer segmentation and audience targeting.

## About this project

This project is a front-end UI concept designed for a digital banking platform. It highlights different customer segments such as satisfied, underserved, underbanked, and unsatisfied users, with a clean layout and responsive design.

## Tech stack

- React
- Vite
- JavaScript
- CSS
- Lucide React icons

## Features

- Responsive landing page layout
- Customer segmentation cards
- Brand-focused banking UI design
- Clean React component structure
- Fast development and build workflow with Vite

## Getting started

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd react-project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open the app in your browser at the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
